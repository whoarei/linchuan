# 邻传 v0.4.0

本版支持 Android arm64、Linux x86_64 和 Windows x64，改善文件接收和浏览器重连，并加入桌面开机启动与托盘。

## 新增与改进

- **固定接收目录**：客户端接收文件和图片后自动保存到系统下载目录下的“邻传”，无需逐个选择位置。设置可更改、打开或恢复默认目录；同名文件自动编号，保存失败可重试。
- **直接打开已保存文件**：消息中可打开文件和所在文件夹。清理应用缓存不删除已保存文件，待保存或保存失败的应用内副本会保留。
- **开机启动与托盘**：Windows／Linux 的设置提供开机启动开关，启用后登录系统时在后台启动。关闭窗口默认收进托盘继续收发；托盘菜单可打开窗口或退出，也可设置为关闭窗口即退出。正常手动启动和再次打开会恢复主窗口。
- **原生后台服务**：桌面后台服务由原生生命周期初始化，隐藏窗口不依赖网页轮询。托盘创建失败时保留普通窗口及关闭退出行为。
- **浏览器临时会话**：同一浏览器、同一访问地址下，24 小时有效期内刷新、关页重开及新标签页复用身份。主动断开撤销凭证，并同步其他标签页退出。
- **减少列表堆积**：离线浏览器会话默认收到“临时会话记录”，无消息和草稿的空会话不再显示；已有文字、文件和草稿记录仍可展开查看。浏览器与原生客户端保持独立身份。
- **草稿修复**：较慢的历史加载不再覆盖刚输入的文字，过时的状态响应不覆盖新的浏览器身份。
- **发布流程**：日常只检查和测试，版本标签触发三平台构建、GitHub Secrets 签名及自动发布；支持独立的 RC 预发布，正式版用户不自动接收 RC。

## 安装与升级

- Windows／Linux：0.3.0 用户可从“关于”检查更新，也可下载安装包覆盖安装。旧版本可直接手动安装本版。
- **Android：本版使用新发布密钥，旧版用户需卸载后重新安装。卸载会清除应用私有的历史和设置，请先保留需要的内容。** 接收目录中已导出的公共文件不属于应用内缓存。
- 数据库升级到 schema 2；保留应用数据的桌面升级沿用设备身份、名称、群聊及历史。旧历史附件不批量导出，可按需保存。
- 开机启动默认关闭，可在设置启用；关闭窗口后继续运行默认开启，仅在托盘可用时生效。Linux 的托盘显示需要桌面环境支持 AppIndicator／StatusNotifier。
- 浏览器访问地址或随机端口变化、清理网站数据后，可能产生新的临时身份；不按名称或 IP 合并历史权限。

## 安装文件

- Windows x64：`Linchuan_0.4.0_x64-setup.exe`
- Linux x86_64：`Linchuan_0.4.0_amd64.deb`、`Linchuan_0.4.0_amd64.AppImage`
- Android arm64：`Linchuan_0.4.0_android_arm64.apk`
- 更新验证：三个桌面 `.sig`、`latest.json`
- 全部文件校验：`SHA256SUMS`

## 验证与边界

发布以同一标签提交的完整检查、三平台构建、Linux 普通／后台启动检查、Android 应用版本与签名及 16 KiB 对齐、桌面更新签名和发布资产回读校验为门槛。自动化包含 33 项 Rust 核心测试、25 项浏览器／原生接口模拟流程和 19 项签名发布策略测试。详情见[0.4 验证范围](https://github.com/whoarei/linchuan/blob/v0.4.0/docs/validation-0.4.md)。

Windows／Linux 真实登录启动、系统托盘菜单、实际安装升级及 Android 厂商目录提供器仍需实机验证。Android 本轮不提供开机启动或后台常驻；移动客户端保持运行后收发。传输仍使用 HTTP，面向可信局域网，不提供离线补发、断点续传或后台常驻保证。
