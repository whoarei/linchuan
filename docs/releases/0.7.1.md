# 邻传 v0.7.1

## 文件接收

- 收到需要确认的多文件消息时，可逐个勾选要接收的附件。「另存为」可为本次接收选择目录。
- 已选文件按从小到大的顺序传输。客户端中已保存的文件可以立即打开。
- 收发两端在传输进度旁显示已传大小、总大小和实时速度。

## 移动端与键盘操作

- 手机浏览器可在聊天页断开当前会话，再重新配对。
- 对话框支持 Tab 循环导航和 Escape 关闭，关闭后焦点回到打开它的按钮。
- 启动失败时可直接重试。发送文字超过 65,536 个 UTF-8 字节时，会在准备附件前提示缩短。
- 改进旧版 Android WebView 的加载和界面布局，接收和发送控件避开系统栏与屏幕缺口。

## 升级与下载

数据库升级至 schema 5，以记录每次接收选择的附件。升级保留设备身份、传输历史和已保存文件。Windows 和 Linux 可在「关于」中检查更新，Android 可覆盖安装同签名的新版 APK。

- Windows x64 `Linchuan_0.7.1_x64-setup.exe`
- Linux x86_64 `Linchuan_0.7.1_amd64.deb` 和 `Linchuan_0.7.1_amd64.AppImage`
- Android arm64 `Linchuan_0.7.1_android_arm64.apk`
- `SHA256SUMS` 用于核对下载文件。
