# 邻传 v0.6.0

本版简化浏览器通信，减少文件传输中的磁盘副本，并让文字和图片自动接收。支持 Android arm64、Linux x86_64 和 Windows x64。

## 调整与改进

- **浏览器只连接当前客户端**：配对后直接进入宿主会话，不再显示设备列表、参与群聊或通过宿主转发给其他设备。切换目标时打开另一台客户端的地址并配对。原生客户端继续支持设备发现、客户端互传及群聊。
- **原文件直接发送**：原生选择或拖入文件后登记文件引用，发送时流式读取原文件，避免先复制整份到应用缓存。群发共用来源引用，各接收者独立读取，进度和结果互不影响。
- **接收只保存一份**：客户端之间传输、浏览器上传至宿主均直接写入接收目录的临时文件，完整后发布为正式文件，不再先写应用缓存再自动导出。接收仍按实际空间预算，默认保留 2 GiB 余量。
- **文字和图片自动接收**：单聊、网页与宿主会话，以及已加入的客户端群聊，纯文字直接送达，纯图片消息（可以附文字）自动接受。含普通文件的整条消息仍需确认，群邀请仍需确认加入。空间不足时显示原因，修复后可重试。
- **浏览器按实际读取记录结果**：小图自动显示，单图自动预览最多 4 MiB、预览总量最多 32 MiB；较大或无法内嵌显示的图片交给下载管理器，避免整图进入内存。下载被拦截时保留逐个下载入口，实际传输完成后才更新送达结果。
- **取消与恢复**：传输中断清理未完成目标文件；接收发布检查点用于数据库提交失败后的恢复。原文件被修改或失效时明确提示，已保存文件和原文件不参与应用缓存清理。

## 升级与使用

浏览器使用当前宿主提供的网页，无需单独安装。页面需保持打开，尚未发送完的文件在刷新或关闭后需要重新选择。原生选择文件后，发送完成前请保留原文件；外部移动、删除或修改可能使历史附件引用失效。粘贴图片等没有稳定原路径的来源仍保留必要缓存。

数据库升级到 schema 3，保留设备身份、会话、历史、接收目录和旧附件；旧缓存继续兼容。旧群若包含浏览器成员，发送时会提示新建仅包含客户端的群聊。建议参与互传的客户端均升级到 0.6.0。

键盘发送沿用 Ctrl + Enter（Windows／Linux）和 ⌘ + Enter（macOS）；Enter 换行。

Windows／Linux 可在“关于”检查更新或手动覆盖安装；Android 沿用 0.4.0 起的发布证书。局域网继续使用 HTTP／WS，面向可信网络；不提供断点续传。

## 安装文件

- Windows x64：`Linchuan_0.6.0_x64-setup.exe`
- Linux x86_64：`Linchuan_0.6.0_amd64.deb`、`Linchuan_0.6.0_amd64.AppImage`
- Android arm64：`Linchuan_0.6.0_android_arm64.apk`
- 更新验证：三个桌面 `.sig`、`latest.json`
- 全部文件校验：`SHA256SUMS`

验证范围见 [0.6.0 验证记录](https://github.com/whoarei/linchuan/blob/main/docs/validation-0.6.0.md)。Android 真机文件选择器、真实系统升级及跨设备 Wi-Fi 验收仍需持续验证。
