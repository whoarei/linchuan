# 邻传 v0.8.2

- 修复 Windows 主窗口未向任务栏提供应用图标的问题。任务栏现在显示透明蓝色「厸」。
- 收紧「厸」左右两部分的间距。应用界面和桌面图标统一使用新版字标。

## 升级与下载

Windows 和 Linux 用户可在「关于」中检查更新，Android 用户可覆盖安装同一签名的 APK。

- Windows x64 `Linchuan_0.8.2_x64-setup.exe`
- Linux x86_64 `Linchuan_0.8.2_amd64.deb` 和 `Linchuan_0.8.2_amd64.AppImage`
- Android arm64 `Linchuan_0.8.2_android_arm64.apk`
- `SHA256SUMS` 用于核对下载文件。
