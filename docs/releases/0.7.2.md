# 邻传 v0.7.2

## 接收同名文件

- 接收文件或使用「另存为」时，若目标目录已有同名文件，会显示新旧文件的大小。可以覆盖原文件、保留两份或跳过。选择「保留两份」时，新文件名才会加上编号。
- 一批文件里有多个重名时，可以统一设置，也可以逐个选择。点「返回」会让这批文件继续待接收，方便重新选择文件或目录。
- 自动接收的图片遇到重名也会等待确认。选择覆盖时，新文件接收完整后才会替换原文件。
- 已被覆盖的附件会在原消息中标明，旧消息的下载链接也随之失效。

## 升级与下载

本版将本地数据库升级至 schema 6，用于记录已被覆盖的附件。Windows 和 Linux 用户可在「关于」中检查更新，Android 用户可覆盖安装新版 APK。

- Windows x64 `Linchuan_0.7.2_x64-setup.exe`
- Linux x86_64 `Linchuan_0.7.2_amd64.deb` 和 `Linchuan_0.7.2_amd64.AppImage`
- Android arm64 `Linchuan_0.7.2_android_arm64.apk`
- `SHA256SUMS` 用于核对下载文件。
