# 邻传 v0.5.2

本版支持 Android arm64、Linux x86_64 和 Windows x64，优化文件接收卡片的操作与状态展示。

## 调整与修复

- **卡片上方统一操作**：待接收时在文件卡片上方显示“拒绝 / 接收”文字按钮，突出“接收”；接收完成并保存后切换为保存副本、打开所在文件夹和打开文件图标。
- **传输中显示进度**：确认接收后在卡片内显示已接收大小、总大小和进度条，保留“取消”入口，避免重复显示同一传输的控制项。
- **多文件整批确认**：同一消息中的多个文件共用一组接收按钮，明确整批接收的范围；各文件保存后仍可分别操作。
- **防止重复提交**：提交接收或拒绝决定期间禁用确认按钮，阻止重复点击。
- **状态更清楚**：在文件信息中显示已接收、已保存、保存失败、已拒绝或已取消等状态，保留保存失败重试及缓存清理后打开已保存文件的能力。
- **适配手机布局**：文件操作移到独立区域，长文件名不再与多个图标挤在同一行，手机上扩大按钮点击区域。

## 升级说明

本版沿用 HTTP／WS、配对流程、数据库 schema 2 和接收目录设置，保留设备身份、会话与历史。Windows／Linux 可在“关于”检查更新或手动覆盖安装；Android 沿用 0.4.0 起的发布证书。0.5.0 的 HTTPS 客户端需升级后才能与 HTTP 版本互传。

保存图标继续将文件副本保存到配置的接收目录，不弹出另存为位置选择框。浏览器使用自身的下载功能，不提供原生文件夹或文件打开操作。

## 安装文件

- Windows x64：`Linchuan_0.5.2_x64-setup.exe`
- Linux x86_64：`Linchuan_0.5.2_amd64.deb`、`Linchuan_0.5.2_amd64.AppImage`
- Android arm64：`Linchuan_0.5.2_android_arm64.apk`
- 更新验证：三个桌面 `.sig`、`latest.json`
- 全部文件校验：`SHA256SUMS`

## 验证范围

发布执行完整自动化检查、三平台构建与签名验证，公开前核对全部九个资产。验证记录见 [0.5.2 验证范围](https://github.com/whoarei/linchuan/blob/main/docs/validation-0.5.2.md)。

局域网 HTTP 面向可信网络，不提供内容加密；本版不包含会议、远程控制或断点续传。自动化检查不替代真实系统覆盖升级和跨设备 Wi-Fi 验收。
