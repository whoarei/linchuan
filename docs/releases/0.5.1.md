# 邻传 v0.5.1

本版支持 Android arm64、Linux x86_64 和 Windows x64，恢复无需导入证书的 HTTP 局域网连接。

## 调整与修复

- **恢复 HTTP／WS**：设备发现、手动地址、浏览器二维码及事件连接统一恢复 HTTP／WS，保留随机端口与配对码，无需独立服务器。
- **移除证书操作**：不再生成、续签或使用本地 CA，移除证书指纹、下载与导入信任的界面和接口。
- **兼容既有 HTTP 设备**：发现与信息接口恢复 protocol=1，可与 0.4.0 的 HTTP 客户端互传；不把 0.5.0 的 HTTPS 地址自动改成明文连接。
- **保留数据与原有功能**：设备 ID、名称、会话、群聊、文件历史和草稿继续沿用；接收目录、Windows／Linux 开机启动和托盘、在线更新保持可用。
- **保留连接检查改进**：设备信息按大小限制读取，保留已知身份核对、消息与群事件签名、发现通道关闭后的退出处理，以及局域网请求直接连接设备的行为。

## 升级说明

- 0.5.0 的 HTTPS 客户端需升级到 0.5.1 才能恢复 HTTP 互传。Windows／Linux 可在“关于”检查更新，或手动覆盖安装；旧版发布与安装包保留。
- Android 沿用 0.4.0／0.5.0 发布证书，可直接覆盖升级。0.3.0 及更早版本因旧签名不同需卸载后重装，请先保留需要的数据。
- 数据库继续使用 schema 2。旧 tls_identity 设置保留但不再读取或使用，无效旧证书数据不会阻止启动；本版不清空既有设备身份和历史。
- 从 HTTPS 切回 HTTP 会改变浏览器 origin，可能需要重新配对；宿主中的旧记录不删除，不跨协议自动授予旧身份的历史访问权。
- 若此前手动安装了邻传本地 CA，HTTP 版本不再需要，可在原系统／浏览器证书管理中自行移除。邻传不自动修改系统信任。

## 安装文件

- Windows x64：`Linchuan_0.5.1_x64-setup.exe`
- Linux x86_64：`Linchuan_0.5.1_amd64.deb`、`Linchuan_0.5.1_amd64.AppImage`
- Android arm64：`Linchuan_0.5.1_android_arm64.apk`
- 更新验证：三个桌面 `.sig`、`latest.json`
- 全部文件校验：`SHA256SUMS`

## 验证与边界

HTTP 内容未加密，面向可信局域网。配对、授权及消息签名不等于传输内容保密。普通局域网 HTTP 页面仍受浏览器音视频安全上下文限制，本版不包含会议或远程控制。

发布要求完整自动化检查、三平台构建、Linux 普通／静默启动、Android 版本／签名及 16 KiB 对齐、桌面更新签名和公开资产校验通过。真实系统升级、跨设备 Wi-Fi、托盘与系统登录启动仍需实机验收。GitHub 下载与签名在线更新继续使用 HTTPS。

详见 [HTTP 连接说明](https://github.com/whoarei/linchuan/blob/v0.5.1/docs/http-connections.md)和 [0.5.1 验证范围](https://github.com/whoarei/linchuan/blob/v0.5.1/docs/validation-0.5.1.md)。
