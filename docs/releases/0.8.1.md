# 邻传 v0.8.1

- 启动、配对、欢迎、关于和扫码访客页统一使用透明蓝色「厸」字标，桌面标题栏和侧栏也采用同一字标。
- Windows 桌面快捷方式、任务栏和系统托盘换用透明蓝色「厸」。Linux 的应用和托盘图标同步更新。

## 升级与下载

Windows 和 Linux 用户可在「关于」中检查更新，Android 用户可覆盖安装同一签名的 APK。

- Windows x64 `Linchuan_0.8.1_x64-setup.exe`
- Linux x86_64 `Linchuan_0.8.1_amd64.deb` 和 `Linchuan_0.8.1_amd64.AppImage`
- Android arm64 `Linchuan_0.8.1_android_arm64.apk`
- `SHA256SUMS` 用于核对下载文件。
