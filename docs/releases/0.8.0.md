# 邻传 v0.8.0

## 收发

- 桌面客户端在「设备」下方新增「收发」，进入后可选「发资料」或「收文件」。
- 「发资料」可把文件、图片和链接放进同一个取件页。同一局域网里的访客用浏览器扫码，即可按需下载或打开链接，无需配对。
- 「收文件」可生成交件码。访客可选填姓名并提交文件或照片，只能看到自己的提交。创建方可查看收件记录并打开接收目录。同名文件会分别保留。
- 创建时可设有效期，也可以提前关闭页面。完全退出邻传会结束扫码页面，已保存的文件继续保留在接收目录。

## 连接端口

- 普通 HTTP 连接优先使用 `51515`。端口被占用时依次尝试其他预置端口，15 个预置端口都不可用时由系统分配空闲端口。连接地址以邻传界面显示为准。

## 升级与下载

本版将本地数据库升级至 schema 7，用于清理中断交件留下的临时文件。Windows 和 Linux 用户可在「关于」中检查更新，Android 用户可覆盖安装同一签名的 APK。

- Windows x64 `Linchuan_0.8.0_x64-setup.exe`
- Linux x86_64 `Linchuan_0.8.0_amd64.deb` 和 `Linchuan_0.8.0_amd64.AppImage`
- Android arm64 `Linchuan_0.8.0_android_arm64.apk`
- `SHA256SUMS` 用于核对下载文件。
