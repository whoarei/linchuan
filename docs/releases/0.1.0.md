# 邻传 v0.1.0

邻传的第一个版本：同一网络内发送文字、图片和文件。每台应用都提供浏览器入口，服务端口由系统分配，无需账户或独立服务器。

## 下载

| 系统 | 安装包 | 说明 |
| --- | --- | --- |
| Android | `Linchuan_0.1.0_android_arm64.apk` | Android 7.0+，64 位 ARM，发布密钥签名 |
| Linux | `.deb` / `.AppImage` | x86_64，推荐 Ubuntu 22.04+ 或兼容发行版 |
| Windows | `.exe` | Windows 10/11 x64，NSIS 安装程序，需要 WebView2 |

`SHA256SUMS` 提供所有安装包的 SHA-256。GitHub 自动生成的 Source code 压缩包是源码，不是应用安装包。

## 功能

- mDNS 自动发现同网应用，也可输入完整地址手动连接。
- 应用中展示浏览器地址、二维码和六位配对码，浏览器配对后双向收发。
- 文字、网址、截图粘贴、原图、多文件及多目标发送；每位接收者分别确认。
- 流式传输、传输进度、拒绝、取消、图片预览及文件下载。
- 浏览器会话隔离，文件大小/数量与临时空间限制。
- 灰白界面与蓝色强调色，支持桌面与手机窄屏。

## 开始使用

1. 在至少一台设备安装并打开邻传，保持应用运行。
2. 应用之间选择附近设备；发现不到时点击「通过地址连接」。
3. 未安装应用的设备打开对方「让其他设备连接」面板中的地址或二维码，输入设备名和配对码。
4. 选择接收设备，添加内容并发送，接收方点击「接收」。文件可另行下载保存。

## 已知限制

- 首版使用 HTTP，未实现传输加密，仅用于可信局域网；配对码不代表加密。
- 应用与网页需要保持运行；手机切后台或锁屏时可能断开。
- 单文件最大 2 GiB，每次最多 64 个文件、8 个接收目标，临时空间预算 10 GiB。
- 文件先上传到发送宿主的临时目录再发送；不支持断点续传或文件夹传输。
- 接收文件临时存放于应用目录。应用中的「下载」会打开系统浏览器，由浏览器保存文件。
- 当前运行记录不承诺跨重启保留；需要保留的文件请下载到个人目录。
- 路由器客户端隔离、防火墙或跨子网可能阻止发现和连接。随机端口不能绕过这些限制。
- Windows 安装包未进行商业代码签名，可能提示未知发布者。

## 验证范围

发布前运行 Rust 核心 HTTP 集成测试、TypeScript 检查、生产构建和 Playwright 浏览器流程测试；构建 Android、Linux、Windows 安装包，并检查 Android 签名。Linux 原生启动通过 Xvfb 验证。详细结果见仓库 `docs/validation.md`。

Android 和 Windows 的真实硬件安装、不同手机厂商的后台行为及真实 Wi-Fi 跨设备发现尚未完成验证；自动化与编译结果不等同于这些真机测试。
