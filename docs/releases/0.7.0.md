# 邻传 v0.7.0

本版为 Windows、Linux 和 Android 加入局域网远程协助。已连接的客户端可以邀请对方观看屏幕。在分享方授权后，观看方可以使用鼠标或触控，并发送键盘输入。分享方可以随时收回控制或结束共享。

## 网页远程协助

- 浏览器配对后出现在「临时会话记录」。分享方打开在线会话并发出邀请，浏览器收到邀请后可选择「加入观看」。
- 普通 HTTP 配对支持观看。需要网页控制时，请在分享方的「连接其他设备 → 配置网页控制」中导入浏览器信任的 HTTPS 证书，使用网页协助地址和对应的配对码。分享整个屏幕后，观看方可以请求控制。
- Windows 控制需要单显示器，Linux 屏幕分享使用单屏 X11，Android 控制需要启用邻传的协助触控权限。Android 采集画面时会通过系统界面确认授权。

## 升级与安装

数据库升级至 schema 4，保留设备身份、文件传输历史、草稿和已有浏览器会话。Windows 和 Linux 可在「关于」中检查更新，Android 可覆盖安装同一签名的新版 APK。

- Windows x64 `Linchuan_0.7.0_x64-setup.exe`
- Linux x86_64 `Linchuan_0.7.0_amd64.deb` 和 `Linchuan_0.7.0_amd64.AppImage`
- Android arm64 `Linchuan_0.7.0_android_arm64.apk`
- `SHA256SUMS` 校验全部发布文件。桌面更新验证使用三个 `.sig` 和 `latest.json`。
