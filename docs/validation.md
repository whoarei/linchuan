# 0.1.0 验证记录

## 已完成的本地自动化

- TypeScript 类型检查与 Vite 生产构建。
- Rust 格式检查与核心 clippy（warnings 视为错误）。
- 6 个核心集成用例：真实随机端口 HTTP 服务之间互传，覆盖以下行为：
  - 端口分配、持久设备 ID、本次启动凭证变化、公开接口不泄露凭证。
  - 浏览器配对、错误配对、未登录访问拒绝、会话记录隔离。
  - 文字接收、重复确认拒绝、应用之间接受/拒绝/取消。
  - 多文件与中文文件名、2 MiB 二进制内容、空文件、下载字节一致和一次性 ticket。
  - 路径逃逸、超限文件、非局域网地址、部分上传、提前完成和错误传输凭证拒绝。
  - 多个浏览器接收者独立同意或拒绝。
- 4 个 Playwright 流程：浏览器配对上传/下载、两个应用核心直传、手机宽度收件与无横向溢出、错误配对提示。
- 两个开启发现的独立核心进程通过本机网络接口自动发现，验证 mDNS 实现能工作；这不是跨物理设备 Wi-Fi 测试。
- 人工查看桌面与手机窄屏截图，确认灰白/蓝色界面与核心操作布局。

## 发布构建检查

已完成一次三平台构建和 Linux 原生启动检查。最终发布使用同一提交的全部成功构建作为门槛： Linux/Windows 桌面构建、Android arm64 release 构建、核心与浏览器测试、Linux 原生启动检查。发布签名、安装包数量、校验和与 Release 状态在发布时核对。

## 尚未验证的范围

Android/Windows 真机安装与运行、跨真实物理设备 Wi-Fi 发现、Android 厂商省电行为、长时间/2 GiB 实际文件传输、低磁盘空间压力及复杂企业网络。不能把模拟手机浏览器当作 Android 原生客户端真机验收。
