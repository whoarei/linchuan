# 0.2 开发验证记录

## 本地自动化

16 个 Rust 集成用例（原有 6 个 + 本轮 10 个）覆盖：

- 原有随机端口、设备身份、配对隔离、中文文件与字节一致、接收/拒绝/取消及越权/超限检查。
- 0.1 device.json 迁移、名称保存、设备公钥保留、浏览器凭证仅存哈希、退出后跨重启撤销。
- 完成文件、消息和文字草稿跨重启保留；离线会话仍可打开；未完成任务显示中断。
- 缓存清理后文件卡片保留、文件不可用、已完成历史状态不被改写。
- 按游标分页无重复、跨浏览器会话与草稿权限隔离；共享文件源不能让未确认的浏览器绕过接收或读取另一位接收者的副本。
- 三个独立实例创建/加入群，群主关闭后其余成员仍能发送群文字和文件，逐人显示部分完成；成员重启并更新随机端口后仍可收发。
- 伪造群资料、冒用其他成员退出、未签名群消息、退出后发送均被拒绝。
- 签名消息重复到达或跨重启重发不重复入库，篡改正文拒绝。
- 数据库注入写入失败时不确认成功、不产生幽灵消息；文件草稿及配额可恢复并重试。

6 个 Playwright 流程覆盖：浏览器单聊文件下载、应用之间直接收发、群邀请与逐人接收、设置改名和草稿/历史恢复、手机列表进入会话及无横向溢出、错误配对提示。

同时检查 Rust fmt/clippy、TypeScript 与生产构建。人工检查桌面三列和手机会话截图，保持灰白与蓝色。

## CI 门槛

同一提交运行以上自动化，构建 Linux x64 DEB/AppImage、Windows x64 NSIS、Android arm64 release APK；Linux 通过 Xvfb 验证原生界面启动嵌入服务，Android 验证 16 KiB ELF 对齐。构建记录以 GitHub Actions 实际结论为准。

## 尚未验证

Android/Windows 真机安装运行、Android 键盘与系统文件选择器、不同厂商后台行为、跨真实 Wi-Fi 网络的组播与群收发、2 GiB 文件及低磁盘长期压力。HTTP 不加密、离线群消息不自动补发。

0.2 当前为开发版本，本轮不创建新的正式 Release。0.1.0 稳定版保留。
