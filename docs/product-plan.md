# 邻传 Linchuan 产品方案

当前版本：0.2.0。0.1.0 安装包作为旧版本继续保留。

后续开发项：[客户端与浏览器自动命名](device-names.md)、浏览器客户端下载入口，尚未包含于 0.2.0 安装包。

## 产品定位

同一网络，随手互传。支持 Android、Linux、Windows 和免安装浏览器入口；每台应用平等参与，使用系统分配的随机端口，没有独立服务器或账户。

## 界面

桌面参考常用聊天软件的信息结构：第一列固定“设备、设置、关于”；第二列显示附近设备和历史会话（含群聊）；第三列显示所选设备或群的历史文字、图片、文件和逐人状态，底部统一输入文字、粘贴截图或添加文件。

手机使用相同内容结构，底部为设备、设置、关于；点击设备/群进入会话，返回列表。进入会话时底部区域留给输入框。整体为灰白与蓝色，减少装饰文案。

离线设备仍可查看历史。历史按稳定设备 ID 归档；设备名称可从设置直接修改并保存，新的发现/探测结果会更新附近设备名称。

## 群聊

- 新建群聊，选择附近设备并邀请；对方确认后加入。
- 群主可修改群名、邀请新成员、重新发送未送达的邀请；成员可退出。
- 每群最多 16 位成员。群主不是转发节点，关闭群主应用后其他已加入成员仍可互传。
- 已加入群的文字直接收录。文件由各接收者分别确认，发送方展开消息查看每台设备的完成、拒绝、取消、失败和进度。
- 一条群消息只显示一个气泡；部分接收成功显示“部分送达”，不标成全员完成。
- 离线设备不自动排队或补发，新加入成员不自动获得旧消息。

## 数据与文件

SQLite 保存设置、已知设备、会话、群资料、成员、消息、附件声明、传输结果及文字草稿，按会话分页读取。首次升级迁移 0.1 的设备 ID 和名称；此前未落盘的内存历史无法补回。

完整文件保存在本机应用数据目录，不随重启清理。文件缓存可从设置清理，文字和原有卡片保留，过期附件显示不可用。清理跳过活动传输文件。未完成的传输在重启后显示中断，不能标为已完成。

单文件最大 2 GiB，每次最多 64 个文件，本机文件预算 10 GiB。文字最多 64 KiB。文件选择和未上传文件不跨重启恢复；文字草稿保存到数据库。

## 浏览器入口

扫码或输入应用地址、配对后双向收发，支持参与群聊。每个浏览器身份的历史、确认和下载权限独立；宿主代理其传输。凭证到期或宿主随机端口改变后，不承诺按名称恢复同一个浏览器身份。

main 开发版在浏览器配对页底部和连接后的“关于”页提供“下载客户端”，新标签页打开 GitHub 最新正式版下载页，包含 Android、Linux、Windows。无需先完成配对即可下载；浏览器主会话界面保持简洁。

## 本轮范围

包含三列/移动界面、设置与关于、持久单聊、分页历史、文字草稿、文件保存与缓存清理、群邀请/加入/退出/直传、签名验证和逐人结果。

公网穿透、TLS 内容加密、离线补发、群历史同步、群主转让、文件夹、断点续传、后台常驻保证、更多平台、商店上架和自动更新继续留到后续。

当前采用 HTTP，仅面向可信局域网；签名用于核对身份与协议内容，不代表内容加密或无条件抵御首次连接的中间人攻击。真实设备、厂商后台限制、复杂 Wi-Fi 与大文件压力仍需持续测试。
