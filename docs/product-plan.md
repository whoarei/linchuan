# 邻传 Linchuan 产品方案

当前版本：0.5.0。0.1.0、0.2.0 安装包作为旧版本继续保留。

本版提供[客户端与浏览器自动命名](device-names.md)、浏览器客户端下载入口、桌面自绘标题栏和窗口控制、[在线更新](updates.md)。

0.4.0 提供[固定接收目录](receive-storage.md)：默认保存到系统下载目录下的“邻传”，设置中可更改或恢复默认。确认接收后自动保存，消息中可直接打开文件和文件夹，失败可重试；同名文件不覆盖。浏览器使用自身的下载设置。

0.4.0 同时提供[浏览器临时会话重连](browser-sessions.md)：浏览器不与原生客户端合并，24 小时有效期内在同一访问地址复用连接身份；离线临时会话默认收起，有内容或草稿的记录仍可展开查看，空会话隐藏。

Windows／Linux 提供[开机启动与托盘](desktop-background.md)：设置可启用开机启动，关闭窗口默认继续后台收发，托盘可打开或退出；Android 本轮保持前台运行方式。

## 产品定位

同一网络，随手互传。支持 Android、Linux、Windows 和免安装浏览器入口；每台应用平等参与，使用系统分配的随机端口，没有独立服务器或账户。

## 界面

桌面参考常用聊天软件的信息结构：第一列固定“设备、设置、关于”；第二列显示附近设备和历史会话（含群聊）；第三列显示所选设备或群的历史文字、图片、文件和逐人状态，底部统一输入文字、粘贴截图或添加文件。

手机使用相同内容结构，底部为设备、设置、关于；点击设备/群进入会话，返回列表。进入会话时底部区域留给输入框。整体为灰白与蓝色，减少装饰文案。

离线设备仍可查看历史。历史按稳定设备 ID 归档；设备名称可从设置直接修改并保存，新的发现/探测结果会更新附近设备名称。

## 群聊

- 新建群聊，选择附近设备并邀请；对方确认后加入。
- 群主可修改群名、邀请新成员、重新发送未送达的邀请；成员可退出。
- 每群最多 16 位成员。群主不是转发节点，关闭群主应用后其他已加入成员仍可互传。
- 已加入群的文字直接收录。文件由各接收者分别确认，发送方展开消息查看每台设备的完成、拒绝、取消、失败和进度。
- 一条群消息只显示一个气泡；部分接收成功显示“部分送达”，不标成全员完成。
- 离线设备不自动排队或补发，新加入成员不自动获得旧消息。

## 数据与文件

SQLite 保存设置、已知设备、会话、群资料、成员、消息、附件声明、传输结果及文字草稿，按会话分页读取。首次升级迁移 0.1 的设备 ID 和名称；此前未落盘的内存历史无法补回。

完整文件保存在本机应用数据目录，不随重启清理。文件缓存可从设置清理，文字和原有卡片保留，过期附件显示不可用。清理跳过活动传输文件。未完成的传输在重启后显示中断，不能标为已完成。

单文件最大 2 GiB，每次最多 64 个文件，本机文件预算 10 GiB。文字最多 64 KiB。文件选择和未上传文件不跨重启恢复；文字草稿保存到数据库。

## 浏览器入口

扫码或输入应用地址、配对后双向收发，支持参与群聊。每个浏览器身份的历史、确认和下载权限独立；宿主代理其传输。凭证到期或宿主随机端口改变后，不承诺按名称恢复同一个浏览器身份。

浏览器配对页底部和连接后的“关于”页提供“下载客户端”，新标签页打开 GitHub 最新正式版下载页，包含 Android、Linux、Windows。无需先完成配对即可下载；浏览器主会话界面保持简洁。

## 本轮范围

包含三列/移动界面、设置与关于、持久单聊、分页历史、文字草稿、文件保存与缓存清理、群邀请/加入/退出/直传、签名验证和逐人结果。

“关于”页支持手动检查正式版本，Windows／Linux 下载签名更新包后确认安装并重启，Android 下载 APK 后由系统安装。更早版本可手动安装 0.5.0；Android 0.4.0 沿用相同发布证书，可直接升级，0.3.0 及更早版本因旧签名不同需卸载重装，详见[在线更新](updates.md)和本版发布说明。

公网穿透、TLS 内容加密、离线补发、群历史同步、群主转让、文件夹、断点续传、后台常驻保证、更多平台、商店上架和静默自动安装更新继续留到后续。

已发布 0.4.0 使用 HTTP；0.5.0 提供 [HTTPS 设备连接](https-connections.md)，保持随机端口及无专门服务节点。客户端按设备身份验证证书，浏览器首次核对指纹并信任对应本地 CA，会议所需的浏览器安全上下文以实际状态为准。首次认识设备仍采用首次使用信任。真实设备、厂商后台限制、复杂 Wi-Fi 与大文件压力仍需持续测试。
