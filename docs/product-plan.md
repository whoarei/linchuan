# 邻传 Linchuan 产品方案

版本：0.1.0 · 状态：实施基线

## 1. 产品定位

同一网络，随手互传。邻传是面向个人设备和局域网内多人的文件、文字、图片传送工具。无需账户、云端或独立服务节点；每台运行应用的设备都是平等的收发端，并向未安装应用的设备提供浏览器入口。

首批平台：Android、Linux、Windows。首版以应用保持前台、设备处于可信局域网为使用条件。

## 2. 用户场景

- 个人：手机与电脑之间发送原图、截图、网址、文字和多个文件。
- 多人：发现同网设备，向一台或多台设备发送，对每个接收者分别确认、显示状态。
- 免安装：浏览器打开对方应用展示的地址或二维码，输入配对码后向应用发送内容，也能接收应用发来的内容。
- 无法自动发现：手动输入含随机端口的地址连接。访客网络隔离仍可能阻止访问。

## 3. 0.1.0 范围

| 能力 | 首版行为 |
| --- | --- |
| 本机信息 | 持久设备 ID、可改设备名、网络地址、二维码、配对码 |
| 动态端口 | 绑定端口 0，由系统分配；本次运行固定，重启允许变化 |
| 设备发现 | mDNS 发布实际端口，在线设备列表；支持手动地址补充 |
| 内容 | 文字、网址、原图、截图粘贴、多文件；文件按原始字节传输 |
| 选择接收者 | 单选或多选应用设备、已配对的浏览器会话 |
| 接收 | 默认先确认或拒绝；文字可复制，图片可预览，文件可保存 |
| 进度 | 上传、等待确认、传输、完成、拒绝、失败、取消；多人独立状态 |
| 记录 | 当前进程会话记录；不承诺重启恢复或永久历史 |
| 文件管理 | 应用数据目录临时保存，退出后下次启动清理；用户另存文件不清理 |
| 发布 | Android arm64 APK、Linux x64 DEB/AppImage、Windows x64 安装包，附校验和 |

首版限制：单文件最大 2 GiB，单次最多 64 个文件；文字不超过 64 KiB；并行目标最多 8 个。为避免移动设备被大量占满，临时存储设总量上限。应用必须显示可理解的失败原因，不把中断标记为成功。

## 4. 主要交互

### 应用首页

视觉采用简洁的灰白中性色和蓝色强调色，不采用绿色风格；减少装饰文案，突出收发操作。

左侧为邻传标识、在线设备与手动连接；主区为文字输入、文件拖拽/选择和待发送列表；收件箱独立展示待确认请求与已完成内容；连接面板展示本机地址、二维码、配对码。窄屏改为分区切换，操作区适合触屏。

### 应用之间

发现/连接设备 → 勾选目标 → 输入文字或添加文件 → 发送 → 各接收方确认 → 传输 → 分别显示结果。发送中支持取消；失败可重新发起。暂不支持断点续传。

### 浏览器入口

打开完整地址 → 输入设备名称及配对码 → 加入 → 看到宿主应用和同一宿主下已配对的会话 → 双向收发。浏览器作为临时会话存在，不独立提供监听地址、不执行局域网发现。页面关闭后不保证接收；大文件通过下载链接交给浏览器下载，避免整文件加载进 JS 内存。

### 保存文件

收到的文件先进入应用私有收件目录。浏览器用下载操作另存；应用提供保存入口，首版可调用系统浏览器下载到用户选择/系统默认目录。Android 不要求广泛存储权限。

## 5. 信任与隐私

- 无注册、无分析上报、无云端中转；静态网页资源随应用打包，断网仍能使用。
- 配对码仅在应用内展示，浏览器连接需要输入；请求接收文件需要单独确认。
- 首版使用局域网 HTTP，未实现传输加密；配对码用于控制访问，不代表端到端加密。界面与使用说明需准确表达。
- 浏览器会话只访问自己的记录；远端设备只获得单次传输凭证，不能读取整个收件箱。
- 固定设备身份不等于可信身份；首版不做永久信任和自动接受。

## 6. 非目标

公网穿透、离线投递、后台常驻保证、系统剪贴板自动同步、文件夹传输、断点续传、端到端加密、macOS/iOS、应用商店上架和自动更新留到后续版本。Android APK 采用发布签名，不把调试 APK 当正式产物；Windows 未购买代码签名证书，系统可能提示未知发布者。

## 7. 验收与发布门槛

1. 两个独立实例获得不同可用端口；重启后设备 ID 保持。
2. 应用端与浏览器端分别完成文字、中文文件名、图片、多文件收发；核对文件字节。
3. 未配对不能读取记录或上传文件；非接收者不能同意或下载；路径不能逃逸收件目录。
4. 拒绝、取消、超限、连接失败不会被展示为成功；部分文件上传不会出现在完成收件箱。
5. 断开外网后仍可在同网使用；自动发现不可用时能手动连接。
6. 三平台构建通过；发布安装产物、SHA-256、版本说明及已知限制。自动化验证与真实设备验证必须分别记录，未做真机验证不能声称已验证。

## 8. 后续路线
