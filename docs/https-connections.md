# HTTPS 设备连接

0.5.0 将设备间传输和浏览器访问统一改为 HTTPS，继续使用随机端口，不增加专门的服务节点。本次只建设连接与证书信任能力，不包含音视频会议。

## 连接与身份

- 每台设备首次启动时生成独立的 ECDSA 本地 CA，签发含当前局域网 IPv4、回环地址和本机名称的短期服务器证书。CA 随应用数据保留，改名、重启和随机端口变化不更换 CA。
- CA 中包含由现有 Ed25519 设备身份签名的公钥绑定。客户端校验证书链、地址、有效期、TLS 握手签名及设备身份；已记录设备的身份变化拒绝连接。第一次认识的设备仍是首次使用信任，不等于预先验证了操作者身份。
- mDNS 公告 HTTPS 能力与随机端口。地址输入只接受局域网 HTTPS；旧 HTTP 设备需要升级，不自动降级明文传输。发现公告本身不作为经过认证的设备信息，须经 HTTPS 验证再保存。
- 文字、附件、群聊控制消息及 WebSocket 事件都经过相同的加密和身份校验。浏览器事件使用 WSS。
- 客户端 WebView 保留独立的本机 HTTP 桥接接口，仅监听 127.0.0.1 和另一个随机端口，不在局域网广播。这样无需修改宿主系统证书信任，也无需放宽 WebView 的 TLS 检查。局域网只暴露 HTTPS。

## 浏览器信任

局域网 IP 的设备自签 CA 不会自动获得浏览器信任。连接面板展示 HTTPS 地址、CA 的 SHA-256 指纹、公共证书下载和首次信任说明。公共证书不包含私钥；证书下载不携带配对码或 owner 凭证。

用户从可信设备取得 CA，核对指纹，再按操作系统／浏览器规则导入信任，随后重新打开 HTTPS 地址。程序不自动安装根证书，不要求全局关闭证书验证。仅越过证书警告不作为会议权限可用的保证；页面显示浏览器实际报告的安全上下文状态。后续麦克风、摄像头和屏幕分享仍需浏览器与系统分别授权。

HTTP 升级到 HTTPS 会改变浏览器 origin，即使 IP 相同也需要重新配对；原临时会话历史仍保留在宿主，不自动授予新浏览器身份。原生设备 ID、名称和已有传输历史不因 HTTPS 升级变化。

本地 CA 的名称及约束限定其局域网用途，服务器叶证书仅含服务端用途。应用数据清除／卸载会导致 CA 变化，浏览器应移除旧信任并重新核对新证书。

## 数据存储

保持 SQLite schema 2，在 app_settings 增加 tls_identity，一条 JSON 原子保存 certificate_pem 和 private_key_pem。私钥仅用于本机签发，不进入 HTTP 信息接口、mDNS、日志、公共证书导出或前端。设备既有 identity_secret、公钥固定规则、名称和历史不变。

服务器叶证书和临时私钥只在内存中保存；当前地址变化时重新签发叶证书，不改变已信任的 CA。CA SHA-256 指纹加入公开设备信息，供人工核对。

CA 有效期为十年，约束为局域网／回环 IPv4 及 .local／localhost 名称。叶证书有效期为三十天，持续运行时每七天重新签发，后台每分钟及读取设备信息时检查地址与续签条件。

## 验证要求

验证真实 HTTPS 传输、浏览器配对与 WSS、CA 跨重启持久化、普通客户端拒绝未信任证书、导入对应 CA 后连接成功、其他 CA／身份伪造／地址不匹配／过期证书被拒绝、明文局域网地址不再接受，以及文字、文件和群聊的原有回归流程。浏览器安全上下文以受信任 CA 的实际测试为准，不以忽略证书错误代替。

本次本地通过：41 项 Rust 测试、27 项 Playwright 流程、23 项发布脚本测试、TypeScript／Vite、Rust fmt／Clippy、工作流 actionlint 及 Android arm64 Tauri 编译检查。TLS 回归包含复制身份绑定冒充 CA、有效 CA 的过期叶证书、过期 CA、地址不匹配、已知身份端点替换、CA 持久化及长期运行续签。Firefox 在独立临时配置中真正信任测试 CA，验证 HTTPS 配对、安全上下文、WSS 通知、文件完整下载、证书导出与关页重开；默认 Chromium 验证未信任 CA 被拒绝。

Linux 发布启动检查已改为从本机接口取得公共 CA，再使用 Python／OpenSSL 的正常证书验证访问 HTTPS。已用核心 CLI 验证该探测链路，含宿主启用 HTTP／HTTPS 代理的环境；局域网探测显式直连，不绕过证书检查。此脚本验证不代替本轮尚未执行的原生 GUI 安装包验收。

本次发布三平台安装包；Windows／Android 真实系统证书安装与跨设备 Wi-Fi 验收仍需实机核对。CI 日常工作流仅增加证书测试依赖和 Firefox，保持不做三平台安装包构建。
